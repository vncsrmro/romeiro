# Romeiro — V2

Uma alternativa independente para comparação com a versão original. A V1 permanece em `../site` e não é modificada por esta versão.

## Executar

Nesta pasta: `npm start`. Endereço local: http://127.0.0.1:4390/

V1: http://127.0.0.1:4388/

## Direção

Marfim, grafite e verde-lima; tipografia Space Grotesk com contraste editorial; layout assimétrico; retratos; projetos com vídeo ao passar o mouse ou receber foco; filtros; acordeões; seis páginas de case com estudos de marca e imagens ampliáveis. Movimento reduzido respeitado conforme a preferência do sistema.

Os arquivos visuais e dados foram copiados para esta pasta. A V2 não depende do servidor da V1, de recursos Framer ou de fontes externas durante o uso. O contato usa o WhatsApp público da InovaSys.

Edite `index.html` para o conteúdo da home, `style.css` para a aparência, `app.js` para interações e seleção das capas. `cases.json` e `case-media.json` contêm o material dos projetos; `case.js` e `case.css` compõem as páginas internas.

O servidor é local e serve apenas no endereço de loopback. Para publicação, use hospedagem estática com a raiz nesta pasta.
